# 遊戯王 ゲートボールシミュレーター (Yu-Gi-Oh! Gateball Simulator)

遊戯王OCGの過去レギュレーション（通称：ゲートボール）をプレイ・またはサポートするためのWebベースのシミュレーターです。
ブラウザ上で動作するため、環境構築は不要で手軽に使用することができます。

## 📝 概要

本プロジェクトは、2004年環境や2011年環境など、過去の特定のカードプール・ルールで遊ぶ「ゲートボール」に特化したツールです。
`index.html`をブラウザで開くだけで、すぐにシミュレーター（またはライフ計算ツール等）として機能するように設計されています。

## ✨ 主な機能（※プロジェクトに合わせて編集してください）

*   **ライフポイント計算機能:** プレイヤー双方のライフポイントの増減を簡単に管理。
*   **ダイス・コイントス:** ゲーム内で必要になるランダム要素を実装。
*   **カウンター機能:** 魔力カウンターやターン数のカウント機能。
*   **レスポンシブ対応:** PC・スマートフォンの両方のブラウザで快適に動作します。

## 🚀 使い方

特別なインストールやサーバーの構築は不要です。

1. 当リポジトリをクローン、またはZIP形式でダウンロードします。
   ```bash
   git clone https://github.com/shogoh/yugioh-gateball-simulator.git
   ```
2. フォルダ内にある `index.html` を、お使いのWebブラウザ（Google Chrome, Safari, Firefox, Edgeなど）で開きます。
3. すぐにツールの利用を開始できます。

*(※もしWebサーバー上でホスティングしている場合は、GitHub PagesなどのURLをここに記載してください)*

## 🛠 使用技術

*   **HTML5**: 構造のマークアップ (`index.html`)
*   **CSS3**: スタイリングとレスポンシブデザイン
*   **JavaScript (ES6)**: ライフ計算や各種シミュレーションロジック
