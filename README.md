# 遊戯王 ゲートボールシミュレーター (Yu-Gi-Oh! Gateball Simulator)

遊戯王OCGの過去レギュレーション（通称：ゲートボール）をプレイ・またはサポートするためのWebベースのシミュレーターです。
ブラウザ上で動作するため、環境構築は不要で手軽に使用することができます。

## 📝 概要

本プロジェクトは、過去の特定のカードプール・ルールで遊ぶ「ゲートボール」に特化したツールです(2026/10時点で2004年4月までのカードプール)。
`index.html`をブラウザで開くだけで、すぐにシミュレーター（またはライフ計算ツール等）として機能するように設計されています。

## 🚀 使い方

特別なインストールやサーバーの構築は不要です。
以下へアクセスして遊んでください。
*[https://shogoh.github.io/yugioh-gateball-simulator/](https://shogoh.github.io/yugioh-gateball-simulator/)*
